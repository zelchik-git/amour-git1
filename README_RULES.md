# 📚 Руководство по системе правил (Non-Coder Edition)

Эта папка содержит **многоуровневую систему правил для ИИ-ассистента** в Google Antigravity IDE (и Cursor). 
Архитектура вдохновлена лучшими практиками enterprise-проекта Aimour, но адаптирована специально под твои задачи.

---

## 🗂️ Как устроена система (4 Уровня)

```
[Твой проект]
│
├── AGENTS.md                                   <-- УРОВЕНЬ 1: Главная Конституция (запрет грузить кодом, язык, безопасность)
│
├── .agents/
│   ├── rules/                                  <-- УРОВЕНЬ 2: Модульные правила (включаются по ситуации)
│   │   ├── 01-web-dashboards-and-interactive-clicks.md  (интерактивные кнопки, автоклики, темная тема)
│   │   ├── 02-data-csv-and-sheets.md                   (CSV, Google Таблицы, защита от сбитых запятых)
│   │   ├── 03-web-scraping-and-parsers.md              (бесплатный парсинг вакансий, чистка данных)
│   │   └── 04-safety-and-anti-breaking.md              (защита от поломок, бэкапы, самопроверка)
│   │
│   └── skills/                                 <-- УРОВЕНЬ 3: Готовые навыки/инструкции для сложных задач
│       ├── interactive-tool/SKILL.md           (как собрать дашборд с кнопками под ключ)
│       ├── vacancy-data-harvester/SKILL.md     (как парсить и фильтровать вакансии)
│       └── deep-audit/SKILL.md                 (как проверить любой файл на скрытые косяки)
│
└── .cursor/rules/                              <-- УРОВЕНЬ 4: Зеркало правил для совместимости с Cursor AI
    ├── 000-core.mdc
    ├── 100-interactive-clicks.mdc
    ├── 200-data-csv.mdc
    └── 300-scraping.mdc
```

---

## 🚀 Что эта система даёт тебе:
1. **ИИ больше не вываливает в чат непонятный код:** Он делает работу внутри файлов сам, а тебе показывает понятное описание на русском языке и ссылку на готовый результат.
2. **ИИ не додумывает отсебятину:** Если в задаче есть развилка — он остановится и спросит тебя перед тем, как что-то менять.
3. **Все инструменты работают в 1 клик прямо в браузере:** Все скрипты оформляются как интерактивные кликабельные кнопки, бейджи и фильтры.
4. **Никаких платных ключей:** Всё работает локально, бесплатно и автономно.
5. **Файлы никогда не ломаются:** ИИ сам себя перепроверяет перед тем, как сказать «готово».
